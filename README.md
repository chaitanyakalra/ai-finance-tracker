# AI Finance Tracker

AI Finance Tracker is an open-source personal finance web application that combines expense tracking, analytics, and AI-powered conversational insights. It provides a React frontend, a Node.js + Express backend with MongoDB, and integrations with large language models (Google Gemini) for conversational finance assistance and multi-agent analysis.

This README replaces the original README with a more detailed project overview, setup instructions, security guidance, API documentation, and contribution notes.

## Features

- Add and manage personal expenses
- Visualize spending statistics and category breakdowns
- Conversational AI chat to ask questions about your expenses
- Multi-agent AI analysis (multiple specialist agents provide perspectives)
- Endpoint for behavioral finance insights generated by an LLM
- Seed script to populate the database with mock data for development

## Tech stack

- Frontend: React (Hooks), Vite or CRA (project folder: `frontend/`)
- Backend: Node.js + Express (project folder: `backend/`)
- Database: MongoDB
- AI: Google Gemini (via environment-configured API key)
- Deployment options: Node server for backend, static hosting for frontend, MongoDB Atlas for DB

## Getting started (development)

### Prerequisites

- Node.js (16+ recommended)
- npm or yarn
- MongoDB (local or Atlas)
- A Google Cloud / Gemini API key (if you want to use the AI features)

### Local setup

1. Clone the repository (keep this private while you verify secrets):

```bash
git clone https://github.com/chaitanyakalra/ai-finance-tracker.git
cd ai-finance-tracker
```

2. Install dependencies for backend and frontend:

```bash
# Backend
cd backend
npm install

# Frontend (in another shell)
cd ../frontend
npm install
```

3. Create `.env` files (use the `.env.example` pattern) — see [Environment variables](#environment-variables).

4. Start MongoDB locally or configure a MongoDB Atlas cluster and set `MONGO_URL`.

5. Start backend and frontend in development:

```bash
# backend (in backend/)
npm run dev   # or `npm start` depending on package scripts

# frontend (in frontend/)
npm run dev   # opens frontend on http://localhost:3000 (or configured port)
```

### Environment variables

Create a `backend/.env` file (do NOT commit this file) with the following values (example):

```
MONGO_URL=mongodb://localhost:27017
DB_NAME=finance_tracker
GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
PORT=8000
CORS_ORIGINS=http://localhost:3000
```

Notes:
- `GEMINI_API_KEY` must be stored securely and never committed to the repository.
- Consider using a secrets manager or CI/CD secret store for production deployments.

## Running the app (quick start)

- With both backend and frontend running, open the frontend URL (usually `http://localhost:3000`) and interact with the UI.
- Use the AI Chat ("AI Financial Assistant") or Multi-Agent tabs to send questions — these call `/api/ai/chat` and `/api/ai/multi-agent` respectively.

## API endpoints

The backend provides a set of REST endpoints under `/api` (see backend/README for the current list). Important endpoints include:

- POST /api/expenses — Add new expense
- GET /api/expenses — Get all expenses
- GET /api/expenses/recent — Get last 10 transactions
- GET /api/expenses/stats — Get spending statistics
- POST /api/ai/chat — AI chat for expense insights (calls configured LLM)
- POST /api/ai/multi-agent — Multi-agent financial analysis
- GET /api/ai/behavioral-insight — Get behavioral finance insights

Usage example (curl):

```bash
curl -X POST http://localhost:8000/api/ai/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"How much did I spend on food this month?"}'
```
